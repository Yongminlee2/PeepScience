# 삐약과학 이미지 발주서 — 스프라이트 15장 + 배경 4장 + 아이콘 + 피처 그래픽

앱: **삐약과학**(Peep Science, `com.peep.science`) — 부품(판자·공·톱니…)을 조합해
물리 퍼즐을 푸는 게임. "삐약" 가족 앱(삐약푸쉬·삐약영어·삐약수학)과 같은 병아리
캐릭터를 씁니다. 이미지 생성 도구로 제작하기 위한 사양서입니다.

## 어떻게 적용되는가 (제일 중요)

이 게임은 **그림이 있으면 그림, 없으면 도형**으로 자동 전환됩니다. 현재 14개
부품·목표물, 수집별 1개와 지형 타일까지 상용화 폴리시 버전이 적용되어 있습니다. 아래 파일을
정확한 파일명으로 `assets/images/parts/`, `assets/images/bg/`에 넣고 다시 빌드하면
**그 파일만** 자동으로 그림으로 바뀝니다. 일부만 넣어도 되고, 순서도 상관없습니다.

## 화면 구조 (부품 그림이 실제로 놓이는 자리)

16:9 가로 화면, 고정 해상도 1600×900px. 화면은 위아래 두 구역뿐입니다.

```
1600px
┌──────────────────────────────────────────────────────────┐ y=0
│                                                              │
│   배경 world{1..4}.png 가 이 화면 전체(1600×900)를 덮는다      │
│                                                              │
│    ▭ 플랭크    ⬤ 공    ⚙ 기어    △ 시소   …               │
│    부품 그림은 이 영역에 "실제 물리 크기"대로 놓인다             │
│    (제일 큰 것도 시소 672×64px, 화면을 꽉 채우지 않음)          │
│                                                              │
│    배경은 여기서 가려지지 않고 전부 다 보여야 한다               │
│    (그러데이션·페이드로 지우지 말 것)                          │  750px
├──────────────────────────────────────────────────────────┤ y=750
│ 트레이 바 (기존 UI, 흰 카드+색 점 - 이번 발주와 무관)          │  150px
└──────────────────────────────────────────────────────────┘ y=900
```

- 아래쪽 150px(트레이 바)는 항상 불투명 UI가 덮으므로 배경 그림이 거기 있어도
  안 보입니다 — 신경 안 써도 됩니다.
- 이 게임은 **중력이 아래로 작용하는 2D 옆면 물리 놀이터**입니다(당구대를 옆에서
  보는 느낌). "정면"은 카메라를 마주보는 얼굴이 아니라 **옆에서 본 모습**입니다.
  공·기어처럼 원형인 건 방향이 안 보이니 상관없지만, 판자·시소·트램폴린처럼
  방향이 있는 것은 반드시 옆모습으로 그려 주세요.

## 1) 부품 12장 + 목표물 2장 + 수집별 1장 → `assets/images/parts/`

### 공통 규칙

| 항목 | 값 |
|---|---|
| 형식 | 투명 배경 PNG (RGBA) |
| 픽셀 크기 계산법 | 물리 크기(m) × **256px/m**, 32px 단위로 올림 (예: 0.24m×256=61.44 → 64) |
| 그림 윤곽 | **= 물리 윤곽(원 또는 직사각형)** — 도형이 캔버스 가장자리까지 거의 꽉 차야 합니다. **여백을 넣지 마세요** — 게임이 렌더링할 때 이 그림을 물리 크기의 1.05배로 살짝 더 키워서 그리므로, 그 5%가 원래 있어야 할 여유분입니다. 그림 자체에 또 여백을 두면 실제 화면에서 원래 물리 크기보다 훨씬 작게 보입니다 |
| 외곽선 두께 | **최종 에셋 기준 4~8px**의 슬림한 코코아색 선. 단, 64px 소형 에셋은 **2~4px**. 검은색(`#000`)과 넓은 암색 면적은 금지합니다. |
| 채도 | **0.35~0.55** (선명한 캔디톤 — v2에서 상향: 저채도 파스텔은 낡아 보였음) |
| 스타일 | 슬림한 코코아색 외곽선 + **소프트 셀 셰이딩 1단계**(밝은면/그늘면 두 톤 + 광택 하이라이트 1개), 넓고 밝은 내부 색면, 통통하고 둥근 실루엣, 모던 캐주얼 퍼즐 게임 느낌, 옆에서 본 정면 |
| 금지 | 3D 렌더 느낌, 과한 그라데이션, 외곽선 없는 밋밋한 플랫, 클립아트풍, 실사 텍스처 |

### 3초 판독 규칙 (v2 핵심)

| metal_ball | 금속 광택 밴드 + 하단 어둡게(묵직함), 고무공과 확실히 구분 |
