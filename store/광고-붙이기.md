# 광고 붙이기 — 애드몹에서 만들 것과 넣을 자리

앱 쪽 작업은 끝나 있다. 남은 건 애드몹 콘솔에서 값 두 개를 만들어
아래 두 자리에 넣는 일뿐이다.

## 1. 애드몹에서 만들 것

`https://admob.google.com` 에서 구글 계정으로 들어간다. 다른 앱(검 강화하기
등)을 이미 올렸다면 같은 계정을 쓴다 — 지급 정보와 세금 정보를 다시 넣지
않아도 된다.

1. **앱 추가** — "앱" → "앱 추가"
   - 플랫폼 **Android**
   - "앱이 스토어에 등록되어 있나요?" → 아직 프로덕션 출시 전이면 **아니요**로
     만들고, 스토어에 올라간 뒤 **앱을 스토어 등록정보와 연결**한다
     (연결해야 스토어 ID 기준으로 정확히 집계된다)
   - 앱 이름 `Peep Science`
   - 만들고 나면 **앱 ID**가 나온다. 생김새는 `ca-app-pub-숫자16자리~숫자10자리`
     (가운데가 **물결표**다)
2. **광고 단위 추가** — 만든 앱 안에서 "광고 단위" → "광고 단위 추가"
   - 형식 **전면 광고**(Interstitial)
   - 이름은 아무거나. 예: `stage-advance`
   - 만들고 나면 **광고 단위 ID**가 나온다. 생김새는
     `ca-app-pub-숫자16자리/숫자10자리` (가운데가 **빗금**이다)
3. **광고 단위 하나 더** — 같은 앱 안에서 "광고 단위 추가"
   - 형식 **배너**(Banner)
   - 이름 예: `home-bottom`
   - 이것도 `ca-app-pub-숫자16자리/숫자10자리` 모양이다
   - 보상형은 만들 필요 없다
4. **개인정보 보호 및 메시지** — 왼쪽 메뉴에서
   - **GDPR 메시지** 만들기 (유럽·영국 이용자용). 앱이 시작할 때 이 창을
     띄우도록 이미 코드가 들어가 있다
   - **미국 주 규정 메시지**도 같이 만들어 두면 된다
   - 둘 다 "게시"까지 눌러야 실제로 뜬다
5. (선택) **app-ads.txt** — 스토어 등록정보의 웹사이트 칸이
   `yongminlee2.github.io/legal/peepscience/` 로 되어 있으므로,
   `yongminlee2.github.io/app-ads.txt` 에 애드몹이 알려주는 한 줄을 올리면
   된다. 없어도 광고는 나오지만 단가가 낮아질 수 있다

## 2. 받은 값을 넣을 자리

두 값은 서로 다른 파일에 들어간다. **물결표 값과 빗금 값을 바꿔 넣으면
앱이 시작하자마자 죽는다.**

**세 값 모두 이미 들어가 있다.** 애드몹 앱을 새로 만들지 않는 한 다시 넣을
일은 없다.

| 값 | 들어간 파일 |
|---|---|
| 앱 ID (`~`) | `android/app/src/main/AndroidManifest.xml` |
| 전면 광고 단위 ID (`/`) | `lib/services/ads.dart` 의 `_realInterstitialAndroid` |
| 배너 광고 단위 ID (`/`) | `lib/services/ads.dart` 의 `_realBannerAndroid` |

넣은 뒤 다시 빌드하면 끝이다.

```
flutter build appbundle --release
```

실제 ID를 넣기 전까지 정식 빌드는 **광고를 아예 요청하지 않는다**
(`Ads._configured`). 실수로 테스트 광고가 이용자에게 보이거나, 잘못된 ID로
구글에 요청이 가는 일은 없다.

## 3. 광고가 뜨는 자리

- **전면 광고, 스테이지를 세 판 넘길 때마다 한 번.** 다음 판으로 넘어가는
  그 순간에만 뜬다
- 장치를 만드는 중이나 실행 중에는 절대 끼어들지 않는다
- **배너는 메인 화면과 월드 목록 맨 아래 두 곳.** 광고를 못 받으면 높이
  0이 되어 두 화면 모두 예전 그대로 보인다
- 게임 화면에는 배너를 붙이지 않는다. 한 번 넣어 보고 뺐다. 16:9 판이
  화면 높이를 꽉 채우고 있어서 띠를 넣으면 판이 12~14% 작아지는데,
  띠 높이를 줄이려 해도 구글이 주는 최소 높이가 50이라 더는 못 줄인다.
  좌우 빈 자리(84)는 광고 최소 너비(320)에 한참 못 미친다
- 인터넷이 없으면 광고만 안 뜨고 게임은 그대로 돌아간다
- 광고 등급은 **전체이용가(G)**로 제한해 두었다

## 4. 콘솔에서 같이 바꿀 것

광고를 넣으면 신고 내용이 달라진다. 빠뜨리면 정지 사유가 된다.

- **앱 콘텐츠 → 광고** — "예, 앱에 광고가 있습니다"
- **앱 콘텐츠 → 데이터 보안** — `플레이스토어-작성내용.md` 6번 표대로
  기기 ID·앱 활동을 **수집·공유(광고 목적)**로 신고
- **개인정보처리방침** — 이미 광고 내용으로 갱신해 두었다
  (`legal/peepscience/privacy.html`)
- 스토어 설명 글에는 광고 이야기를 넣지 않는다. 광고 유무는 콘솔이
  자동으로 표시한다
