# 제출 체크리스트 — 삐약과학 / Peep Science

Play Console에 올릴 때 위에서부터 순서대로 하면 되는 단계별 목록. 각 줄이 한 단계다.

1. [ ] Play Console → **앱 만들기** — 이름 "Peep Science", **기본 언어 영어(en)**, 앱/게임 → 게임, 다운로드 비용 없음 선택
2. [ ] 콘솔에서 **언어 15개 추가** — en-US(기본) · ko · ja · zh-CN · zh-TW · zh-HK · es · pt-BR · de · fr · it · ru · id · vi · th
3. [ ] **스토어 등록정보** → `legal/peepscience/store-listing.md`에서 언어별 **앱 이름·짧은 설명·자세한 설명**을 해당 언어 상자에 붙여넣기(한 언어씩 저장하며 진행). 앱 이름이 30자에 딱 붙는 언어가 몇 개 있으니 콘솔이 세는 숫자를 확인한다
4. [ ] **그래픽 자산** 업로드 — 앱 아이콘 `store/art/icon_6.png`(512×512), 그래픽 이미지 `store/art/feature_graphic.png`(1024×500). 휴대전화 스크린샷은 **언어별**로 `store/업로드/스크린샷/<언어코드>/01_home.png ~ 04_clear.png`. 언어별로 안 올리면 기본 언어(en) 스크린샷이 대신 쓰인다
5. [ ] **카테고리·태그** — `store/플레이스토어-작성내용.md` 4번대로 게임 → 퍼즐, 태그 후보 중 선택
6. [ ] **앱 콘텐츠 → 개인정보처리방침** — URL 입력:
   `https://yongminlee2.github.io/legal/peepscience/privacy.html`
   (배포 완료. 스토어 등록정보의 "웹사이트" 칸에는 `https://yongminlee2.github.io/legal/peepscience/`)
7. [ ] **앱 콘텐츠 → 데이터 보안 설문** — `store/플레이스토어-작성내용.md` 6번 표 그대로 입력(전부 "수집 안 함" 방향)
8. [ ] **앱 콘텐츠 → 콘텐츠 등급 설문(IARC)** — `store/플레이스토어-작성내용.md` 7번 표 그대로 입력 → 전체이용가 확인, 타깃 연령은 "어린이와 성인 모두"로 신고
9. [ ] **앱 콘텐츠 → 수익화 관련 선언** — 해당 SDK가 전혀 없는 빌드이므로 문항 그대로(전부 "아니요") 답한다
10. [ ] **테스트 트랙** — 프로덕션 대신 **비공개 테스트(내부 테스트)** 트랙을 먼저 만들고 테스터 이메일(본인 계정 등) 등록
11. [ ] **릴리스 생성** → AAB 업로드 — 경로 `build/app/outputs/bundle/release/app-release.aab` (아래 4절 빌드 완료 후 생성됨)
12. [ ] **출시명·출시노트** 칸에 `legal/peepscience/release-notes.txt` 를 통째로 붙여넣기 — 콘솔이 `<en-US>` 같은 묶음표로 15개 언어를 한 번에 받는다
13. [ ] 저장 후 "출시 전 검토" 페이지에서 오류·경고 0인지 확인
14. [ ] 비공개 테스트 트랙에 게시 → 등록한 테스터 계정으로 설치해 실행까지 확인
15. [ ] 문제 없으면 프로덕션 트랙으로 승격(또는 별도 프로덕션 심사 제출)

## 참고

- 서명: `android/keystore.properties`가 이미 연결돼 있다. AAB도 APK와 같은
  `signingConfig`를 타므로 별도 서명 작업이 필요 없다.
- 준비물은 전부 만들어져 있다 — 위 15단계는 콘솔에 붙여 넣고 업로드하는 일만 남았다.
- 스토어 문구를 쓰는 원칙(돈 이야기·"과학상자" 단어를 넣지 않는 이유)은
  `store/플레이스토어-작성내용.md` 맨 위 안내를 따른다.
