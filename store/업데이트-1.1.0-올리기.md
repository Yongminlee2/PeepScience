# 1.1.0 (빌드 6) 올리기

광고와 힌트를 넣은 첫 업데이트다. **광고를 새로 넣었기 때문에 앱 콘텐츠 신고를
먼저 고쳐야 한다.** 순서대로 하면 된다.

올릴 파일: `build/app/outputs/bundle/release/app-release.aab`
버전: **1.1.0**, 버전 코드(빌드 번호) **6**

---

## 1. 앱 콘텐츠 고치기 (정책 → 앱 콘텐츠)

### 1-1. 광고
- "앱에 광고가 포함되어 있나요?" → **예, 광고가 있습니다** → 저장

### 1-2. 광고 ID
- "앱에서 광고 ID를 사용하나요?" → **예**
- 용도 → **광고 또는 마케팅** 에 체크 (분석·사기 방지도 체크 가능)
- 저장

### 1-3. 데이터 보안 (가장 중요)
`store/플레이스토어-작성내용.md` 6번 표를 그대로 넣는다. 요약:

- 데이터를 수집하거나 공유하나요? → **예**
- 전송 중 암호화 → **예**
- 삭제 요청 방법 제공 → **아니요**
- 데이터 유형 네 가지 체크, 모두 **수집 + 공유**
  - 위치 → 대략적인 위치
  - 앱 활동 → 앱 상호작용
  - 앱 정보 및 성능 → 진단 정보
  - 기기 또는 기타 ID
- 각 항목: 일시적 처리 **아니요** / 사용자 선택 **아니요(필수)** /
  목적 **광고 또는 마케팅 · 분석 · 사기 방지, 보안, 규정 준수**
- 마지막 화면에서 **제출**

### 1-4. 타겟층 및 콘텐츠
- 이미 **13세 이상**으로 되어 있으면 그대로 둔다. 광고도 13세 이상 등급까지만
  받도록 앱에 맞춰 두었다.

### 1-5. 개인정보처리방침
- 주소는 그대로: `https://yongminlee2.github.io/legal/peepscience/privacy.html`
- 내용은 광고·힌트 광고 기준으로 이미 고쳐 올려 두었다.

---

## 2. 새 버전 만들기 (테스트 및 출시 → 프로덕션)

1. **새 버전 만들기**
2. App Bundle에 `app-release.aab` 올리기 → 1.1.0 (6) 으로 뜨는지 확인
3. 버전 이름: `6 (1.1.0)` (자동으로 채워지면 그대로)
4. 출시 노트: `legal/peepscience/release-notes-1.1.0.txt` 내용을 **통째로** 붙여
   넣기 — `<ko-KR>` 같은 묶음표 덕분에 15개 언어가 한 번에 들어간다
5. **다음** → 경고·오류 확인 → **프로덕션으로 출시 시작** (또는 검토 제출)

> 아직 프로덕션에 한 번도 안 올린 상태라면(이번이 첫 공개) 출시 노트는
> 업데이트용 말고 `release-notes.txt`(첫 출시용)를 쓰는 게 자연스럽다.

## 3. 애드몹 쪽 (한 번만)

- **개인정보 보호 및 메시지 → GDPR 메시지** 만들고 **게시** (유럽 이용자 동의 창)
- 스토어에 올라간 뒤 애드몹에서 **앱을 스토어 등록정보와 연결**
- (선택) `app-ads.txt` 올리기

---

## 4. 출시 후 확인

- 스토어에 **"광고 포함"** 표시가 자동으로 붙는다 (설명 글은 고칠 필요 없음)
- 스토어에서 받은 앱은 **업로드 키로 서명된 정식 빌드**다. 개발용 폰에 깔려 있는
  것(디버그 키 재서명)과 서명이 달라서, 스토어 버전을 받으려면 폰에서 앱을
  지우고 받아야 한다. 이때 진행 기록과 개발자 모드가 지워진다.
